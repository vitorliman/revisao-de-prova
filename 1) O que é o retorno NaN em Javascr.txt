2)É possível adicionar uma configuração CSS de múltiplas formas em um código HTML:
Sim
É possível inserirmos uma configuração CSS dentro de um elemento: <p style="color:green">
Outra forma de incluirmos o CSS é adicionarmos a tag <style> no <head> de nossa página e declarar as propriedades para os elementos dentro dessa tag:<style> h2{font-size}; <style>
Podemos criar uma pagina de CSS e linkar essa pagina em nosso HTML fazendo com que toda a pagina sofra as alterações feita. <link href:"style.css">
Em geral o que muda é a facilidade de criação, umas sendo mais fáceis e rápidas que outras.

5)O que significa a propriedade display no CSS? Compare o comportamento de block,
inline e inline-block:

Define o comportamento de exibição de um elemento e como ele se organiza na página.
BLOCK:O elemento ocupa toda a largura disponível da tela e força uma quebra de linha
INLINE:O elemento fica na mesma linha que os outros, mas não aceita definições de largura ou altura
INLINE-block:Fica na mesma linha como o inline, mas permite ajustar largura, altura e margens como um bloco
